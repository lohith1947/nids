PHASE 6: LOOPBACK EVALUATION
--------------------------------------------------------------------------------

FACT: NO LOOPBACK DATASET FOUND. The CICIDS2017 sample contains no 127.0.0.1 traffic. Live tests generate synthetic loopback traffic but do not persist it. To perform a controlled loopback evaluation, capture and label a dataset of benign loopback flows (e.g., local HTTP, DNS, SSH, database connections) and malicious loopback flows (e.g., localhost SYN floods, local port scans). Minimum recommended: 500 benign + 500 attack loopback flows, labeled by class.

INFERENCE: Without a labeled loopback dataset, a controlled ML
evaluation on loopback traffic is impossible. The current model was
trained exclusively on CICIDS2017, which contains no loopback flows.

RECOMMENDATION: Capture a labeled loopback dataset before declaring
the model safe for loopback environments.
